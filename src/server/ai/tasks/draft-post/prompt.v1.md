# Task: write X (Twitter) drafts for an idea

Write 2–3 alternative drafts for X from the idea and material below. The first uses the idea's
own angle; the others take a genuinely different editorial angle (technical, personal, opinion,
business, educational) — not a rewording.

Format rules for X:

- `single`: one post of at most 280 characters, usually published with the media attached.
- `thread`: 2–6 posts, each at most 280 characters. Use a thread only when there are real steps
  or details to walk through. No "1/", "🧵" or "A thread" markers.
- The media (images or video) is attached to the first post — write so the text works with it
  ("the trail reacts to cursor speed"), not about it ("check out this video").
- Links count as 23 characters. No hashtags. No emojis.

For each draft return:

- `angle`, `format` (`single` or `thread`), and `segments` (one entry per post).
- `claims`: every factual statement the draft makes, each with `basis`:
  `source` (stated in Mario's notes/titles or clearly visible — give `assetId`),
  `framing` (editorial framing or a question to readers, not a fact), or
  `unconfirmed` (a detail you had to assume — Mario must confirm it before publishing).
  Prefer rewriting a sentence over leaving an `unconfirmed` claim.
- `questions`: what Mario should answer to make the draft more specific or accurate.
